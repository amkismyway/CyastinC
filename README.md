# Machine Learning-Guided Selection for Cystatin C Testing

This repository contains the complete, reproducible analysis for a study that developed and cross-cycle validated machine-learning models to identify U.S. adults whose cystatin C-based estimated glomerular filtration rate (eGFRcys) was more than 30% lower than their creatinine-based estimate (eGFRcr).

## Main result

In 4,158 eligible adults from NHANES 1999-2002, 342 (8.23%) met the primary discordance definition. XGBoost achieved a repeated cross-validated AUROC of 0.794 (bootstrap 95% CI, 0.772-0.816). Testing the 20% of adults with the highest predicted risk identified 56.4% of discordance cases.

## Reproducing the analysis

1. Open the notebooks in Google Colab.
2. Run them in numerical order.
3. Each notebook downloads official public NHANES XPT files or consumes the ZIP generated by the preceding notebook.
4. Do not upload participant-level derived datasets to GitHub. They can be regenerated from the public CDC files.

The notebooks use the NHANES 1999-2000 and 2001-2002 cystatin C surplus-serum samples, special cystatin C survey weights, published laboratory recalibration equations, and race-free creatinine-based kidney function estimation.

## Primary outcome

```text
eGFRcys < 0.70 × eGFRcr
```

The model is intended to **rank patients for confirmatory cystatin C testing**, not to replace laboratory measurement or diagnose chronic kidney disease.

## Models

- Logistic regression
- Elastic-net logistic regression
- Random forest
- XGBoost

Preprocessing was performed inside each training pipeline. Model evaluation used 5-fold cross-validation repeated five times and bidirectional NHANES cycle holdout validation.

## Data availability

All source data are publicly available from the U.S. Centers for Disease Control and Prevention NHANES website. The repository intentionally excludes participant-level derived data. Aggregate results, figures, and analysis code are included.

## Important limitations

- The study is retrospective and cross-sectional.
- The cystatin C subsample was selected using a complex design.
- Model development used historical NHANES cycles.
- The analysis requires external validation in contemporary clinical cohorts.
- Race/ethnicity was included as a candidate predictor and should be evaluated in a prespecified race-free sensitivity analysis before clinical deployment.
- The model is not approved for clinical use.
