# Analysis Data Dictionary

| Variable | Meaning |
|---|---|
| `RIDAGEYR` | Age in years |
| `RIAGENDR` | Sex as coded by NHANES |
| `RIDRETH1` | NHANES race/ethnicity category |
| `CREATININE_CALIBRATED` | Standardized serum creatinine, mg/dL |
| `LBXSBU` | Blood urea nitrogen, mg/dL |
| `LBXSAL` | Serum albumin, g/dL |
| `LBXSGL` | Serum glucose, mg/dL |
| `BMI` | Body mass index, kg/m2 |
| `WAIST_CM` | Waist circumference, cm |
| `MEAN_SBP` | Mean available systolic blood-pressure readings, mm Hg |
| `MEAN_DBP` | Mean available diastolic blood-pressure readings, mm Hg |
| `HEMOGLOBIN` | Hemoglobin, g/dL |
| `CRP_MG_DL` | C-reactive protein, mg/dL |
| `UACR_MG_G` | Urine albumin-to-creatinine ratio, mg/g |
| `DIAGNOSED_DIABETES` | Self-reported clinician-diagnosed diabetes |
| `DIAGNOSED_HYPERTENSION` | Self-reported clinician-diagnosed hypertension |
| `SMOKING_STATUS` | Never/former/current smoking category |
| `ANY_CVD` | Composite self-reported cardiovascular disease indicator |
| `DISCORDANCE_30_CALIBRATED` | 1 when eGFRcys is more than 30% lower than eGFRcr |
| `HIDDEN_CKD_CALIBRATED` | 1 when eGFRcr >=60 and eGFRcys <60 mL/min/1.73 m2 |
