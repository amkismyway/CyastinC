# Pre-Submission Checklist

- Replace all bracketed author, email, GitHub, and PMID placeholders.
- Have a nephrologist and a biostatistician review the kidney equations, survey weighting, and model comparison.
- Run and report a race-free sensitivity model and subgroup calibration/fairness analysis.
- Run a secondary hidden-CKD prediction analysis or clearly label it as descriptive only.
- Verify every reference against PubMed and format for the selected journal.
- Select a target journal and reformat word count, abstract, tables, and declarations.
